# Workflow References

Facts every pipeline cites, kept in one place so no pipeline restates them. A pipeline cites one of these by
path or by ID; it never copies its content.

| File | Holds | Cited as |
|---|---|---|
| `bounds.md` | Every loop cap in the layer and the five rules for reaching one | B1–B18 |
| `optional-gates.md` | The shape of every review or QA ask, what is never optional, what a decline costs, opting in later | G50 |
| `dispatch-brief.md` | What every dispatch carries, the handoff matrix between agents, and how the Implementation Note is assembled | I1 |

A new file belongs here only when two or more pipelines would otherwise state the same fact. Detail that
serves one pipeline stays in that pipeline.
