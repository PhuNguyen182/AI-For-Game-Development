# Replay Test

Synthesized from the rules in [stable-hashing-and-ordering.md](stable-hashing-and-ordering.md) and the Edit Mode conventions of `unity-test-framework`. The seam is the one the tick owner already calls (`core-scene-integration` → `tick-and-interpolation.md`): `MatchSimulation.Tick(tick, stepSeconds, command, contacts)` and `MatchSimulation.State`. `ReplayFrame`, `ReplayFixtures` and `MatchStateHash` are test-side or module names standing for the project's own.

## What the test needs from Core

| Seam | Fact that decides |
|---|---|
| Constructor takes the seed | RNG built inside from the seed (`nrandom-random-generation`); no ambient generator |
| `Tick(tick, stepSeconds, command, contacts)` | One tick per call; the harness passes the tick index and the fixed step, exactly as the tick owner does; never a clock read |
| `MatchStateHash.Compute(simulation.State)` | Core function: `StableHash` over every outcome-bearing field in a fixed order, entities by id; excludes caches, view state, pooled buffers |
| Recorded frames | Per tick: the `PlayerCommand` and the contact list Core read, from a fixture or generated from a second, separately seeded RNG |

**Caveat:** a seam is missing → the test cannot be written; return `Needs-decision`, `Next: csharp-engineer` (Core API), not a test that pokes private fields.

## Three checks, in cost order

| Check | Catches | Misses |
|---|---|---|
| Two fresh runs in one process, compare per tick | Hidden static state, unseeded RNG, wall-clock reads, order that changes run to run within a process | Anything identical within one process: `string.GetHashCode`, `HashCode` seeds |
| Compare against a committed golden hash list | Per-process hash dependence, runtime or compiler drift, an unintended rule change | Nothing it ran on; it proves only the runners that executed it |
| Same golden list in every runner (Edit Mode, dotnet mirror, Player per target) | Mono vs CoreCLR vs IL2CPP drift, per-platform float divergence | Platforms never run |

**Caveat:** regenerate the golden list only for an intended rule change, in the same commit as that change, and say so in the commit body; a silently regenerated golden file hides the regression it exists to catch.

## Sizing

| Parameter | Fact that decides |
|---|---|
| Ticks | At least one full match or session of the rule under test; divergence often starts late (accumulated float error, rare branch) |
| Seeds | At least 2 fixed seeds per test; a single seed hides seed-dependent branches |
| Inputs | Include the rule's boundary inputs from `risk-based-test-planning`, not only idle ticks |
| Failure message | First diverging tick; the field-level dump at that tick is what the investigator needs |

```csharp
using System.Collections.Generic;
using _Project.Scripts.Match.Core;
using NUnit.Framework;

namespace _Project.Scripts.Match.Tests.EditMode
{
    public sealed class MatchReplayTests
    {
        private const int TickCount = 3600;
        // Must equal the production TickSettings.StepSeconds.
        private const float StepSeconds = 1f / 60f;

        [TestCase(1u)]
        [TestCase(48271u)]
        public void Replay_SameSeedAndInputs_SameHashEveryTick(uint seed)
        {
            IReadOnlyList<ReplayFrame> frames = ReplayFixtures.Frames(seed, TickCount);
            ulong[] first = this.Run(seed, frames);
            ulong[] second = this.Run(seed, frames);

            for (int tick = 0; tick < TickCount; tick++)
            {
                Assert.That(second[tick], Is.EqualTo(first[tick]), $"First divergence at tick {tick}");
            }
        }

        [TestCase(1u)]
        public void Replay_MatchesGoldenHashes(uint seed)
        {
            IReadOnlyList<ReplayFrame> frames = ReplayFixtures.Frames(seed, TickCount);
            ulong[] golden = ReplayFixtures.GoldenHashes(seed);
            ulong[] actual = this.Run(seed, frames);

            for (int tick = 0; tick < TickCount; tick++)
            {
                Assert.That(actual[tick], Is.EqualTo(golden[tick]), $"Drift from golden at tick {tick}");
            }
        }

        private ulong[] Run(uint seed, IReadOnlyList<ReplayFrame> frames)
        {
            MatchSimulation simulation = new MatchSimulation(seed);
            ulong[] hashes = new ulong[frames.Count];
            for (int tick = 0; tick < frames.Count; tick++)
            {
                ReplayFrame frame = frames[tick];
                simulation.Tick(tick, StepSeconds, frame.Command, frame.Contacts);
                hashes[tick] = MatchStateHash.Compute(simulation.State);
            }

            return hashes;
        }
    }
}
```

**Caveat:** NUnit attributes only, no `UnityEngine.TestTools`, so the same file runs in Edit Mode and in a `dotnet test` mirror (`core-tests-without-unity`). Golden data lives in a C# source file (a `static readonly ulong[]`, regenerated by a test helper), so both runners compile the same bytes; never a path built from `Application.dataPath`.

**Caveat:** a production desync report carries a tick and a seed; feed its recorded inputs to the same harness and bisect on the first diverging tick before reading code.
