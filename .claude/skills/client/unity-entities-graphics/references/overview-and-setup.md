# Overview, Requirements & Project Setup

Covers SKILL.md step 2 (platform/pipeline confirmation) and the package's own framing of what it is and isn't.

## Manual
- [Entities Graphics package (index)](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/manual/index.html) — frames Entities Graphics as a system that "collects the data necessary for rendering ECS entities, and sends this data to Unity's existing rendering architecture," rather than being a standalone render pipeline itself. URP/HDRP still own content authoring and rendering-pass definitions.
- [Entities Graphics Overview](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/manual/overview.html) — the bridge between ECS and Unity's existing rendering system; its baking system converts `MeshRenderer`/`MeshFilter` into `RenderMesh` components, `LODGroup` hierarchies into `MeshLODComponent`s, and GameObject `Transform`s into `LocalToWorld` components. At runtime, entities with `LocalToWorld`/`RenderMesh`/`RenderBounds` are organized into batches rendered through the SRP Batcher. Two ways to create renderable entities: bake a Prefab (preferred, best data layout), or use `RenderMeshUtility.AddComponents` at runtime.
- [Requirements and compatibility](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/manual/requirements-and-compatibility.html) — requires **Unity 2022 LTS or later**. **Built-in Render Pipeline is not supported at all.** HDRP is fully supported on 2022 LTS+. URP is supported on 2022 LTS+, but **only the Forward+ rendering path** — Forward/Deferred are not covered. Platform support varies: Android is URP-only (no HDRP); PlayStation/Xbox support both; Web platforms are not supported.
- [Getting Started](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/manual/getting-started.html) — entry point; recommends checking the feature matrix and requirements/compatibility pages before starting any implementation.
- [Installing Entities Graphics](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/manual/creating-a-new-entities-graphics-project.html) — the simplest path is starting from Unity Hub's "3D (URP)" or "3D (HDRP)" project template, which comes pre-configured with the right settings; installing into an existing project instead (Package Manager → add `com.unity.entities.graphics` by name) auto-installs ECS dependencies but still requires manually enabling SRP Batcher and checking color-space settings (linear only).
- [Entities Graphics Feature Matrix](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/manual/entities-graphics-versions.html) — compares URP vs. HDRP support for shaders (Lit/Unlit/Decal — HDRP-only/Particle — URP-only/LayeredLit/LitTessellation), lighting (sun, point/spot, probes), post-processing (motion blur, temporal AA). Both pipelines support **linear color space only**. LOD crossfade is unsupported on both. Texture streaming, ray tracing, and streaming virtual texturing are not yet implemented. Skinning/mesh deformations are experimental on both. The package states it's in active development toward full feature parity across pipelines.

## API
- [Unity.Rendering namespace](https://docs.unity3d.com/Packages/com.unity.entities.graphics@6.6/api/Unity.Rendering.html) — 17 classes, 41 structs, 2 enums; home of `RenderMeshUtility`, `RenderMeshArray`, `MaterialMeshInfo`, `RenderMeshDescription`, `RenderBounds`, `RenderMeshUnmanaged`, and the rest of the rendering component set covered in [rendering-components.md](rendering-components.md).
