# Post Processing Stack v2 (Legacy, Built-in Render Pipeline)

Covers `com.unity.postprocessing` (resolved package version 3.5.4), the legacy post-processing stack that targets Unity's Built-in Render Pipeline for projects that predate URP's Volume-based post-processing. The package is in maintenance mode — new projects on URP/HDRP should use the built-in Volume framework instead, but this stack remains the correct choice for Built-in Render Pipeline projects.

## Manual
- [Post Processing Stack v2 — Manual index](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/manual/index.html) — landing page; overview of `PostProcessLayer` (added to a camera), `PostProcessVolume` (holds effect settings), and the trigger-based volume blending system.
- [Requirements](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/manual/requirements.html) — Unity 2018.1+ compatibility; supports Built-in Render Pipeline, URP 7.x on specific LTS versions, and SRP generally.
- [Installation](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/manual/Installation.html) — install via Package Manager (Window > Package Manager > All packages > Post Processing).
- [Quick start](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/manual/Quick-start.html) — walkthrough for adding a `PostProcessLayer` to the camera, creating a `PostProcessVolume`, and adding effects via the Add Effect button.

Note: the manual's left-hand table of contents is rendered client-side and did not appear in a plain fetch of `manual/index.html` (only footer/legal links resolved there). The three sub-pages above were confirmed individually by direct fetch; other manual pages may exist (e.g. a dedicated effect-list or anti-aliasing page) but were not confirmed and are not listed here to avoid guessing filenames. A guess at `manual/Effects.html` and `manual/quick-start.html` (lowercase) both returned HTTP 404 — filenames on this manual are case-sensitive.

## Package API
Namespace: `UnityEngine.Rendering.PostProcessing` (assembly `Unity.Postprocessing.Runtime.dll`). The API index page (`api/index.html`) did not render a browsable class list via fetch — it returned only header/footer chrome (logo, docs-site link, legal links), no namespace/class links — the same JS-driven-index limitation seen elsewhere in Unity package docs. Every class below was instead confirmed individually by direct fetch of its own API page; only classes that returned real content are listed.

- [PostProcessLayer](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.PostProcessLayer.html) — the component added to a camera that actually renders post-processing; key members: `antialiasingMode`, `volumeLayer`, `volumeTrigger`, `fog`, `temporalAntialiasing`, `fastApproximateAntialiasing`, `subpixelMorphologicalAntialiasing`, `sortedBundles`, methods `Render()`, `RenderOpaqueOnly()`, `GetBundle<T>()`, `GetSettings<T>()`, `ResetHistory()`, `Init()`.
- [PostProcessVolume](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.PostProcessVolume.html) — MonoBehaviour holding a profile, blended by proximity/priority; key members: `isGlobal`, `weight`, `priority`, `blendDistance`, `sharedProfile`, `profile` (instantiated copy), `HasInstantiatedProfile()`.
- [PostProcessProfile](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.PostProcessProfile.html) — ScriptableObject container asset for a set of effect settings; key members: `settings` (list), `isDirty`, `AddSettings()`, `GetSetting<T>()`, `HasSettings()`, `RemoveSettings()`, `TryGetSettings<T>()`.
- [PostProcessEffectSettings](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.PostProcessEffectSettings.html) — base class for every effect's settings, ScriptableObject; key members: `active`, `enabled` (BoolParameter), `IsEnabledAndSupported()`, `GetHash()`, `SetAllOverridesTo()`.
- [PostProcessEffectRenderer&lt;T&gt;](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.PostProcessEffectRenderer-1.html) — generic base class for writing a custom effect's renderer, paired to a `PostProcessEffectSettings` subclass `T`; key members: `settings` property, `Init()`, `Render()`, `Release()`, `ResetHistory()`, `GetCameraFlags()`.
- [Bloom](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.Bloom.html) — built-in effect settings; key members: `intensity`, `threshold`, `softKnee`, `diffusion`, `anamorphicRatio`, `color`, `dirtTexture`, `dirtIntensity`, `fastMode`, `clamp`.
- [ColorGrading](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.ColorGrading.html) — built-in effect settings; key members: `gradingMode` (HDR/LDR/External), `lift`/`gamma`/`gain`, `colorFilter`, `temperature`, `tint`, `saturation`, `hueShift`, `contrast`, channel mixer, `tonemapper` (selects the tonemapping algorithm — there is no separate `Tonemapper` class), `toneCurve*` params, `externalLut`, `ldrLut`, `postExposure`.
- [Vignette](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.Vignette.html) — built-in effect settings; key members: `intensity`, `color`, `mode` (classic/mask), `center`, `smoothness`, `rounded`, `opacity`.
- [DepthOfField](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.DepthOfField.html) — built-in effect settings; key members: `aperture`, `focalLength`, `focusDistance`, `kernelSize`.
- [MotionBlur](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.MotionBlur.html) — built-in effect settings; key members: `sampleCount`, `shutterAngle`.
- [ChromaticAberration](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.ChromaticAberration.html) — built-in effect settings; key members: `intensity`, `fastMode`, `spectralLut`.
- [Grain](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.Grain.html) — built-in effect settings; key members: `colored`, `intensity`, `size`, `lumContrib`.
- [AmbientOcclusion](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.AmbientOcclusion.html) — built-in effect settings; key members: `intensity`, `radius`, `quality`, `mode` (incl. Multi Scale Volumetric Obscurance), `ambientOnly`, `color`, `blurTolerance`, `noiseFilterTolerance`, `upsampleTolerance`, `thicknessModifier`, `directLightingStrength`, `zBias`.
- [AutoExposure](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.AutoExposure.html) — built-in effect settings; key members: `eyeAdaptation` (Progressive/Fixed), `filtering`, `keyValue`, `minLuminance`, `maxLuminance`, `speedUp`, `speedDown`.
- [LensDistortion](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.5/api/UnityEngine.Rendering.PostProcessing.LensDistortion.html) — built-in effect settings; key members: `centerX`, `centerY`, `intensity`, `intensityX`, `intensityY`, `scale`.

All effect settings classes above (`Bloom`, `ColorGrading`, `Vignette`, `DepthOfField`, `MotionBlur`, `ChromaticAberration`, `Grain`, `AmbientOcclusion`, `AutoExposure`, `LensDistortion`) inherit from `PostProcessEffectSettings` and share its `IsEnabledAndSupported()` method. Other built-in effects (e.g. Screen-Space Reflections, Dithering, Fog integration) were not individually fetched/confirmed and are intentionally omitted rather than assumed from memory.
