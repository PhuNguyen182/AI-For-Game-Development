# Post-Processing Effect Availability & URP Effect List

Covers which post-processing effects Unity supports per render pipeline (Built-in RP via the Post Processing v2 package, URP, and HDRP), plus the full URP Volume Override effect list with a purpose/key-property summary for each individual effect page.

## Manual — Effect Availability Reference
- [Post-processing](https://docs.unity3d.com/6000.5/Documentation/Manual/post-processing-and-full-screen-effects.html) — hub page for Unity's post-processing and full-screen effects documentation across all render pipelines.
- [Introduction to post-processing](https://docs.unity3d.com/6000.5/Documentation/Manual/PostProcessingOverview.html) — explains that effect availability depends on which render pipeline (Built-in, URP, HDRP) a project uses, since each pipeline has its own post-processing solution.
- [Post-processing effect availability reference](https://docs.unity3d.com/6000.5/Documentation/Manual/post-processing-effect-availability-reference.html) — source comparison table itself (Unity 6000.5); ~21 effects compared across Built-in RP (Post Processing v2 package), URP, and HDRP.
- [Post-processing and full-screen effects in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-and-full-screen-effects-urp.html) — URP-specific landing page linking to Volume setup guides and the Effect List reference.
  - [Introduction to post-processing in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/integration-with-post-processing.html) — explains URP's integrated Volume-based post-processing system; notes URP is **not** compatible with the legacy Post Processing Stack v2 package, and covers mobile/VR considerations.
  - [Add post-processing in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/add-post-processing.html) — step-by-step guide to enabling post-processing on a Camera, creating a Volume, and adding/configuring Volume Overrides (e.g. Bloom).
  - [Volumes in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/volumes-landing-page.html) — landing hub for Volumes, Volume Profiles, and Volume Overrides, with links to setup and troubleshooting pages.

### Effect-by-effect availability (from the comparison table)
- [Ambient Occlusion (SSAO) in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-ssao.html) — darkens creases/contact points to simulate blocked ambient light; also available in HDRP ([Override-Ambient-Occlusion](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Override-Ambient-Occlusion.html)) and Built-in RP via PPv2 ([Ambient-Occlusion](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Ambient-Occlusion.html)).
- [Anti-aliasing — Camera Inspector reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/camera-component-reference.html#rendering) — post-process anti-aliasing (FXAA, SMAA, TAA) is a Camera "Rendering" setting in URP rather than its own Volume Override; also available in HDRP and PPv2.
- Auto Exposure — **not available in URP**; available in HDRP ([Override-Exposure](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Override-Exposure.html)) and Built-in RP via PPv2 ([Auto-Exposure](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Auto-Exposure.html)).
- [Bloom Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-bloom.html) — available in all three (HDRP [Post-Processing-Bloom](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Bloom.html); PPv2 [Bloom](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Bloom.html)).
- [Channel Mixer Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Channel-Mixer.html) — available in all three; in PPv2 it's part of the combined [Color-Grading](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Color-Grading.html) effect rather than a standalone page.
- [Chromatic Aberration Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-chromatic-aberration.html) — available in all three (HDRP [Post-Processing-Chromatic-Aberration](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Chromatic-Aberration.html); PPv2 [Chromatic-Aberration](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Chromatic-Aberration.html)).
- [Color Adjustments Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Color-Adjustments.html) — available in all three; PPv2 groups it under [Color-Grading](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Color-Grading.html).
- [Color Curves Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Color-Curves.html) — available in all three; PPv2 groups it under [Color-Grading](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Color-Grading.html).
- Fog — **not available in URP**; available in HDRP ([Override-Fog](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Override-Fog.html)) and Built-in RP via PPv2 ([Deferred-Fog](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Deferred-Fog.html)).
- [Depth of Field in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/depth-of-field-urp.html) — available in all three (HDRP [Post-Processing-Depth-of-Field](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Depth-of-Field.html); PPv2 [Depth-of-Field](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Depth-of-Field.html)).
- [Film Grain Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Film-Grain.html) — called "Grain" in the comparison table; available in HDRP ([Post-Processing-Film-Grain](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Film-Grain.html)) and, per the table, an older pinned PPv2 doc version (`com.unity.postprocessing@2.3/manual/Grain.html`, not the usual `@latest` pattern — not independently spot-verified).
- [Lens Distortion Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Lens-Distortion.html) — available in HDRP ([Post-Processing-Lens-Distortion](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@9.0/manual/Post-Processing-Lens-Distortion.html), pinned at package version 9.0 per the table) and PPv2 (table extraction returned `.../manual/Lens-Distortion` with no `.html` extension — flagged as unconfirmed, likely a truncation in extraction rather than the real href).
- [Lift, Gamma, and Gain Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Lift-Gamma-Gain.html) — available in all three; PPv2 groups it under [Color-Grading](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Color-Grading.html).
- [Motion Blur Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Motion-Blur.html) — available in all three (HDRP [Post-Processing-Motion-Blur](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Motion-Blur.html); PPv2 [Motion-Blur](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Motion-Blur.html)).
- [Panini Projection Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Panini-Projection.html) — available in URP and HDRP ([Post-Processing-Panini-Projection](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Panini-Projection.html)) only; **not available** in Built-in RP/PPv2.
- Screen Space Reflection — **not available in URP**; available in HDRP ([Override-Screen-Space-Reflection](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Override-Screen-Space-Reflection.html)) and Built-in RP via PPv2 ([Screen-Space-Reflections](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Screen-Space-Reflections.html)).
- [Shadows Midtones Highlights Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Shadows-Midtones-Highlights.html) — available in URP and HDRP ([Post-Processing-Shadows-Midtones-Highlights](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Shadows-Midtones-Highlights.html)) only; **not available** in Built-in RP/PPv2.
- [Split Toning Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Split-Toning.html) — available in URP and HDRP ([Post-Processing-Split-Toning](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@9.0/manual/Post-Processing-Split-Toning.html), pinned at package version 9.0 per the table) only; **not available** in Built-in RP/PPv2.
- [Tonemapping Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-tonemapping.html) — available in all three; HDRP has a dedicated [Post-Processing-Tonemapping](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Tonemapping.html) page, PPv2 groups it under [Color-Grading](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Color-Grading.html).
- [Vignette Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-vignette.html) — available in all three (HDRP [Post-Processing-Vignette](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Post-Processing-Vignette.html); PPv2 [Vignette](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Vignette.html)).
- [White Balance Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-White-Balance.html) — available in all three; PPv2 groups it under [Color-Grading](https://docs.unity3d.com/Packages/com.unity.postprocessing@latest?subfolder=/manual/Color-Grading.html).

Note: HDRP/PPv2 links use Unity's `@latest`/`@X.Y`-pinned package-doc URL pattern (`https://docs.unity3d.com/Packages/<package>@<version>?subfolder=/manual/<Page>.html`). This pattern and its Bloom/Auto Exposure/Fog rows were directly spot-verified by fetch (the `@latest` links client-side redirect to HDRP package 17.6 and PPv2 package 3.5 respectively as of this research). The remaining per-effect HDRP/PPv2 hrefs above were read directly off the live availability-reference page's table by the fetch tool but were not each individually re-fetched.

## Manual — URP Effect List
- [Post-processing Volume Overrides reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/EffectList.html) — the landing page itself (Unity 6000.5); lists 18 Volume Override effects available in URP.
- [Troubleshooting volumes](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/volumes-troubleshooting.html) — covers the common issue of Volume settings not updating via scripting, with fixes: add a Global Volume to the scene, or recache initial values via `VolumeManager`.
- [Bloom Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-bloom.html) — creates light fringes from bright image areas; key properties: Threshold, Intensity, Scatter, and an optional lens dirt texture.
- [Channel Mixer Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Channel-Mixer.html) — mixes how much each input color channel (Red/Green/Blue) contributes to a selected output channel.
- [Chromatic Aberration Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-chromatic-aberration.html) — simulates color fringing along light/dark boundaries; single key property: Intensity (0–1, 0 disables the effect).
- [Color Adjustments Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Color-Adjustments.html) — overall tone/brightness/contrast grading; key properties: Post Exposure, Contrast, Color Filter, Hue Shift, Saturation.
- [Color Curves Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Color-Curves.html) — curve-based color grading; key properties: Master, Red/Green/Blue, Hue Vs Hue, Hue Vs Sat, Sat Vs Sat, Lum Vs Sat.
- [Color Lookup Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-color-lookup.html) — applies a LUT texture for color grading; key properties: Lookup Texture, Contribution (blend amount).
- [Depth of Field in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/depth-of-field-urp.html) — blurs areas outside a focal plane to simulate camera focus; configured via focus distance, aperture, and blur intensity properties.
- [Film Grain Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Film-Grain.html) — simulates film grain texture; key properties: Type (preset or custom texture), Intensity, Response.
- [Lens Distortion Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Lens-Distortion.html) — warps the image to simulate camera lens distortion; key properties: Intensity, X/Y Multipliers, Center, Scale.
- [Lift, Gamma, and Gain Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Lift-Gamma-Gain.html) — three-way ASC CDL color grading via Lift (shadows), Gamma (midtones), and Gain (highlights) trackballs.
- [Motion Blur Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Motion-Blur.html) — blurs moving objects to simulate exposure blur; key properties: Mode (Camera Only / Camera and Objects), Quality, Intensity, Clamp.
- [Panini Projection Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Panini-Projection.html) — cylindrical projection for wide field-of-view scenes that keeps vertical/radial lines straight; key properties: Distance, Crop to Fit.
- [Add screen space lens flares in URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/shared/lens-flare/post-processing-screen-space-lens-flare.html) — Screen Space Lens Flare override; generates regular/reversed/warped flares and streaks from the same bright areas Bloom uses, with adjustable chromatic aberration.
- [Shadows Midtones Highlights Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Shadows-Midtones-Highlights.html) — independent hue/lightness control per tonal range; key properties: Shadows/Midtones/Highlights trackballs, Shadow Limits, Highlight Limits, Graph View.
- [Split Toning Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-Split-Toning.html) — tints shadows and highlights separately by luminance; key properties: Shadows color, Highlights color, Balance.
- [Tonemapping Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-tonemapping.html) — remaps HDR values to display range; key properties: Mode (None, Neutral, ACES), HDR Output options (Paper White, brightness limits, hue shift).
- [Vignette Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/post-processing-vignette.html) — darkens/desaturates image edges to draw focus to center; key properties: Color, Center, Intensity, Smoothness, Rounded toggle.
- [White Balance Volume Override reference for URP](https://docs.unity3d.com/6000.5/Documentation/Manual/urp/Post-Processing-White-Balance.html) — removes unrealistic color casts so white objects render white; key properties: Temperature, Tint.
