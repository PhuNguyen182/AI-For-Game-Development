## Scripting API — namespace roots

| Member | Description |
|---|---|
| `UnityEngine.Animator` | Component driving Animator Controller playback and parameters. See [animator-component.md](animator-component.md). |
| `UnityEngine.AnimatorController` (asset) / `UnityEditor.Animations.AnimatorController` (editor API) | State-machine asset and its editor-only manipulation API. See [animator-controller.md](animator-controller.md). |
| `UnityEngine.AnimatorOverrideController` | Runtime clip-swap wrapper. See [animator-override-controller.md](animator-override-controller.md). |
| `UnityEngine.AnimationClip` / `UnityEngine.AnimationEvent` / `UnityEngine.AnimationCurve` | Clip data, event payloads, curve data. See [mecanim-overview.md](mecanim-overview.md). |
| `UnityEngine.Avatar` / `UnityEngine.AvatarMask` / `UnityEngine.AvatarIKGoal` | Humanoid rig mapping, body-part masking, IK goal targets. See [avatar-setup.md](avatar-setup.md). |
| `UnityEngine.StateMachineBehaviour` | Per-state script attached inside the Animator Controller graph. See [animator-controller.md](animator-controller.md). |
| `UnityEngine.Playables.PlayableGraph` / `Playable` / `PlayableOutput` and the `Animation*Playable` family | Low-level programmatic animation graph API. See [playables-api.md](playables-api.md). |
| `UnityEngine.Animation` (legacy) | Pre-Mecanim playback component, maintenance-only. See [mecanim-overview.md](mecanim-overview.md). |

See [scripting-api.md](scripting-api.md) for the full member-level cross-reference across all of the above.
