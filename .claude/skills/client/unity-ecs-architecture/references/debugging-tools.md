# Debugging & Editor Tools

Covers SKILL.md step 10 (verifying the actual archetype/system layout, not just the code's intent).

## Manual
- [Entities Hierarchy window reference](https://docs.unity3d.com/Packages/com.unity.entities@6.6/manual/editor-hierarchy-window.html) — `Window > Entities > Hierarchy`; browse/search entities per World, inspect an entity's actual components, switch between Authoring/Runtime/Mixed data modes.
- [Systems window reference](https://docs.unity3d.com/Packages/com.unity.entities@6.6/manual/editor-systems-window.html) — `Window > Entities > Systems`; view the actual system hierarchy grouped by `ComponentSystemGroup` and confirm real update order/placement.
