## Scripting API — namespace roots

| Member | Description |
|---|---|
| `UnityEngine.Physics2D` | Static class holding global 2D physics settings and query methods (raycasts, overlap tests, layer collision matrix), the 2D counterpart to `UnityEngine.Physics`. |
| `UnityEngine.Rigidbody2D` | 2D rigid body dynamics component. |
| `UnityEngine.Collider2D` | Abstract base for all 2D collider shapes. |

For built-in 3D physics instead, see the sibling `unity-3d-physics` skill. For ECS/DOTS-native physics, see `unity-physics`.
