# Framework backlog

Open work on the agent framework (`.claude/`) found while working in this repo: a wrong rule, a gap in an agent or skill, a hook that misfires. Game work goes to `.workflow/backlog.md` (`/plan-game`), never here.

- Created from `.claude/templates/framework-backlog.md` by the session-start hook when missing. The framework repo git-ignores its copy; a game project commits its own (`/new-project` step 5).
- Add a row when found; close it with what closed it (commit sha or path). State: `Open` · `Done: <sha or path>` · `Recorded` (known, accepted as is) · `Recorded (GD decision)` · `Deferred`.
- Never a secret or player PII; cite a credential id or a path.
