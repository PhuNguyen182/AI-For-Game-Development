# KEY=value, KEY: value, "key": "value" for any key ending in a credential word (DB_PASSWORD, client_secret,
# storePassword). A quoted value counts from 8 characters, a bare one from 12. A value that starts with $, %, {, <
# or * is a lookup or a placeholder ($VAR, ${VAR}, %VAR%, <token>, ****). A bare value after `key =` (spaces, as code
# writes it) must end at a space, quote or line end, so `token = GetToken();` is not a secret.
