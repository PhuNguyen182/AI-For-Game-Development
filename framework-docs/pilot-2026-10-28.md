# Pilot — framework v2, 2026-10-28

Project: `Unity/Temp Project` ("Tap Rush"), Unity 6000.0.83f1, URP, hyper-casual, Android + iOS. Every task ran in a fresh headless Claude Code session in the project (`claude -p … --settings .claude/settings.json`), so it loaded the copied framework exactly as a GD's machine would. AskUserQuestion is unavailable headless; each session took the recommended option and logged the question.

## Context cost (`/context`, fresh session)

| | pre-slim | v2 |
|---|---|---|
| Total at start | 61.1k | 41.2k |
| Memory files (CLAUDE.md + rules) | 23.5k | 5.3k |
| Custom agents | 3.5k | 2.3k |
| Skills listing | 9.9k (most names only) | 9.9k (every description shown) |

Memory files load into every subagent too, so the 18.2k saving repeats per dispatch.
