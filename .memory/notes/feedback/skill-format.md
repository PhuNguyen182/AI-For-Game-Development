Every skill item is a titled bullet with a short description; more lines are fine, each line short, no prose; never trim a criterion to save lines. A skill may add checklist.md beside SKILL.md, only '- [ ] **title:** short description' lines. Frontmatter adds when_to_use, argument-hint and arguments when needed. Scripts use any programming language that runs and fits the task; a code-heavy reference may move its code to scripts/. **Why:** the GD ordered this while reviewing the skill template on 2026-11-02, for higher accuracy without long prose. **How to apply:** write or edit any skill to framework-docs/skill-template.md; verify-layer now fails the format, and all skills were migrated on 2026-11-02. A soft size limit never justifies cutting a check.
